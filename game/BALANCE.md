# バランス調整ログ

自動テストプレイ (`node sim/run.js <試合数> <チーム0難易度> <チーム1難易度> <シード>`) と
Playwright によるブラウザ実プレイを繰り返して調整した記録。

## 計測指標

- **勝率対称性**: 同難易度で 50/50 に近いこと (マップ・処理順の公平性)
- **接戦率**: 塗り差8%未満の試合の割合 (高いほど「最後までわからない」)
- **キル数/試合**: 多すぎるとリスポーン待ちだらけの体験になる
- **スペシャル回数/試合**: 乱発すると大味になる
- **インク切れ時間**: 長いと「撃てないストレス」
