# INK RUSH (インクラッシュ) — 企画書

スプラトゥーンにインスパイアされた、スマホブラウザで遊べる 2D トップダウン陣取りインクシューター。

## コンセプト

- **90秒の塗り合戦**。地面をインクで塗り、試合終了時に塗り面積が多いチームの勝ち
- **2 vs 2**: プレイヤー + 味方Bot vs 敵Bot×2
- 縦持ち・片手〜両手親指で完結する操作
- 1試合90秒のスキマ時間設計。リザルト→即リマッチ

## コア体験 (スプラトゥーンらしさの翻訳)

| スプラトゥーン | INK RUSH での実装 |
|---|---|
| インクで地面を塗る | 弾の飛沫と着弾スプラッシュでグリッドセルを塗る |
| イカ潜行 | SWIMボタン長押し: 自インク上で高速移動+インク急速回復+被弾半径縮小 |
| 敵インクのデバフ | 敵インク上は大幅減速+スリップダメージ (体力下限あり、それだけでは死なない) |
| インクタンク | 射撃で消費、潜行で急速回復。切れると撃てない |
| スペシャル | 塗った量でゲージが溜まり、「インクバースト」(周囲大塗り+ダメージ) を発動 |
| ナワバリバトル | 制限時間終了時の塗り率で勝敗。上部に塗り合いメーター表示 |

## 画面・操作 (縦360×640 論理解像度、端末にフィットスケール)

- アリーナ全体が1画面に収まる固定カメラ (視認性・戦況把握のしやすさ優先)
- **左半面**: どこでもタッチで出現する仮想スティック → 移動 & 向き
- **右下**: FIRE ボタン (長押し連射)。射撃中は移動方向へ発射、近くの敵へ緩い自動照準
- **FIRE の左**: SWIM ボタン (長押しでイカ潜行)
- **右上寄り**: SPECIAL ボタン (ゲージ満タンで発光)
- HUD: 上部に塗り合いメーター+残り時間、自機足元にインクタンクリング

## ルール詳細

- マップ: 360×640、8pxセルの塗りグリッド。180度回転対称の障害物配置 (公平性)
- リスポーン: 倒されたら3秒後に自陣スポーンから復帰、1.5秒無敵
- 敵インクダメージでは HP20 未満にならない (キルは必ず射撃/スペシャルで)
- 試合終了時、塗り率の高いチームの勝利。同率はドロー

## Bot AI

- 0.25秒間隔で意思決定 (個体ごとにジッタ)
- 状態: **塗り優先** (未塗装/敵色の濃い地点へ移動しつつ道を塗る) / **交戦** (視線が通る近距離の敵を偏差+ノイズ付きで狙う) / **回復** (インク切れ時に自インクで潜行)
- 終盤 (残り20秒) は塗り重視に寄る
- 難易度はエイムノイズ・反応間隔で調整

## 技術構成

```
game/
├── index.html        # エントリ (ES modules、要ローカルサーバ)
├── src/
│   ├── constants.js  # 全バランスパラメータ (調整はここに集約)
│   ├── rng.js        # シード付き乱数 (再現可能なシミュレーション用)
│   ├── map.js        # 障害物・スポーン・グリッド
│   ├── engine.js     # 純粋ロジック (Node/ブラウザ両対応、固定60Hz)
│   ├── bot.js        # Bot AI
│   ├── render.js     # Canvas 2D 描画
│   ├── input.js      # タッチ/マウス入力 (仮想スティック)
│   └── main.js       # ゲームループ・画面遷移
├── sim/run.js        # ヘッドレス自動対戦シミュレータ (バランス検証)
├── build.js          # 単一HTMLへのバンドル → dist/inkrush.html
├── BALANCE.md        # テストプレイ・調整ログ
└── DESIGN.md         # このファイル
```

エンジンは入力→状態遷移が決定的 (シード乱数) で、描画と完全分離。
これにより Bot 4体の自動対戦を Node で数百試合回して勝率・塗り率・キル数などを計測し、
パラメータ調整 → 再計測のループでバランスを取る。

## 遊び方

```bash
cd game && python3 -m http.server 8000
# スマホと同じLANなら http://<PCのIP>:8000 をスマホブラウザで開く
```

または `node game/build.js` で生成される `game/dist/inkrush.html` (自己完結・約50KB) を
そのままスマホに送って開くだけでも動く。
