# games/

rakurun 関連のミニゲーム置き場。

## RAKURUN DASH (`rakurun-dash.html`)

ワンタップ操作のエンドレスランナー(ハイパーカジュアル)。HTML1枚・依存ゼロで、スマホのブラウザでそのまま動く。

### 遊び方

- ファイルをブラウザで開くだけ(ローカルなら `npx serve games` などでもOK)
- **タップ / Space / ↑**: ジャンプ
- **空中でもう1回タップ**: 2段ジャンプ
- 障害物(岩・トゲ)はジャンプで回避、**鳥は接地したままくぐる**のが基本(慌ててジャンプすると当たる)
- コイン1枚 = 15点。スコア = 走行距離(m) + コイン
- ベストスコアは localStorage に保存

### ゲームデザインメモ

- 速度は距離に応じて 340→760 px/s へ漸増。ただし**画面の論理幅に応じて上限をキャップ**(縦持ちスマホは視界が狭く、反応時間が物理的に足りなくなるため)
- 障害物の出現間隔・パターン構成は距離ベースで難化(`diffRampDist`)
- 調整用の定数は `T` オブジェクトに集約

### 自動テストプレイ

`window.__game` にデバッグハンドル(状態・障害物座標・入力関数)を公開しており、Playwright でヒューリスティックなボットを注入して難易度検証を行った:

- 無操作: 数秒で死亡(ゲームに「牙」があること)
- 人間相当の雑ボット(反応ジッタ±60ms・6%の見落とし): 1プレイ 150〜420m(25〜70秒)
- 上級ボット(2段ジャンプ活用): 最高速度でも 700m 級 — 全パターンがクリア可能=理不尽死がないこと
