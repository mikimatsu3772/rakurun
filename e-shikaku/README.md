# E資格 30日間トレーニング

JDLA E資格の合格に向けた、演習アプリと学習フォローの仕組み。

- **学習期間**: 2026-07-27 (Day 1) 〜 2026-08-25 (Day 30 / 試験想定日)
- **演習アプリ**: [app/](./app/) — 4択79問のドリル。これが学習の主役
- **学習プラン**: [plan.md](./plan.md) — 日別カリキュラム
- **進捗記録**: [progress.md](./progress.md) — 毎日のチェックリストと模試スコア

## 演習アプリ

毎日ここで問題を解く。プランとチェックリストは、その周りの管理にすぎない。

```
app/
├── index.html     # アプリ本体 (UI とロジック)
├── questions.js   # 問題バンク — 問題を足すのはこのファイルだけ
└── build.mjs      # 単一ファイル化 (配布用)
```

### 使い方

`app/index.html` をブラウザで開くだけ。ビルドもサーバも不要。

3つの演習モードがある。

| モード | 中身 |
|--------|------|
| ランダム 10問 | 全分野から出題。実力の確認に |
| 弱点復習 | 間違えた問題だけを再出題。正解すると復習キューから抜ける |
| 未挑戦の問題 | まだ一度も解いていない問題から |

分野別 (応用数学 / 機械学習 / 深層学習基礎 / CNN・画像 / RNN・NLP / 生成モデル / 強化学習 / 開発環境) にも解ける。
解答記録は localStorage に残るので、分野ごとの正答率が溜まっていく。
キーボードは `1`〜`4` で解答、`Enter` で次の問題。

**選択肢は出題のたびに並べ替えられる。** 「正解はいつも1番目」で解けてしまうと演習にならないため。同じ問題を解き直しても位置で覚えることはない。

### 問題を追加する

`questions.js` の配列に足すだけ。`c` は正解の選択肢の添字 (0始まり)。

```js
{
  f: "深層学習基礎",              // 分野名。既存の分野名に合わせると集計される
  q: "問題文 (HTML可)",
  a: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  c: 0,                          // 正解の添字
  e: "解説 (HTML可)"
}
```

模試や黒本で間違えた問題をここに書き足していくと、自分専用の弱点問題集になる。

### 配布用に1ファイルにまとめる

```bash
node app/build.mjs            # app/dist/index.html を生成
node app/build.mjs out.html   # 出力先を指定
```

`questions.js` を HTML に埋め込むので、スマホに送る・どこかにホストするときはこちらを使う。

## 毎朝のリマインド (補助)

```
毎朝 6:55 (JST)
  └─ GitHub Actions (.github/workflows/e-shikaku-daily.yml) が起動
       ├─ progress.md を読んで進捗を確認
       ├─ 今日 (Day N) のタスクを plan.md から取得
       └─ トラッキングIssue (#4) に「今日やること + 遅れの有無」をコメント
          → GitHub の通知 (メール/アプリ) で届く

あなた (毎日)
  ├─ plan.md の当日タスクを実施
  └─ progress.md のチェックボックスを更新してコミット
```

> スケジュール実行はデフォルトブランチ (main) 上のワークフローのみ動くため、
> このPRをマージした時点から毎朝の通知が始まる。
> 手動テストは Actions タブから workflow_dispatch で実行できる。
> 試験が終わったら Issue #4 をクローズすれば通知は止まる (期間外も自動スキップ)。

## 使い方

1. 毎日 `plan.md` で当日のタスクを確認する
2. 学習が終わったら `progress.md` の該当日のチェックボックスを `[x]` にする
3. 模試・章末問題のスコアは `progress.md` 下部の記録表に追記する
4. 週末 (Day 7, 14, 21, 28) は消化できなかったタスクの回収日。遅れをここで吸収する

## 遅れたときのルール

- **1日遅れ**: 翌日に無理に2日分詰めず、直近の予備日 (各週末) で回収
- **3日以上遅れ**: プランを圧縮する。優先度は「深層学習 > 機械学習 > 応用数学 > 開発環境」
  (出題比率が深層学習に大きく偏っているため)
